## 实现规格

- `AdvancedQAService.check_variant` 只读取同租户的 Canonical/Variant 投影、既有 Variant 投影和 RightsRecordVersion 投影，生成符合 `qa-report.schema.json` 的追加式报告；不修改任何业务事实，不调用网络、模型或平台。
- 相似度默认使用标准库确定性词元序列比对；可注入只读 `SimilarityPort` 提供审计可复算的外部评分。低于调用方给出的 `min_similarity` 生成失败 finding；既有 Variant 达到 `duplicate_similarity` 则生成重复度失败 finding，并跳过同一版本自身。
- AI 标识检查只在 `ai_generated=True` 时启用，要求 Variant 顶层或块级 disclosure 含 AI/人工智能/生成式标识；广告检查只在 `advertising_required=True` 时启用，要求 disclosure 非空，并在给出 `required_ad_disclosure` 时要求包含该固定文本。
- 素材权利检查通过可替换 `RightsPort` 或内置 RightsRecordVersion 投影执行，验证租户、Schema、`verified` 状态、有效期、market/locale、media 和 permitted_use；`rights_required=True` 且没有可用授权时失败。任何跨租户输入先拒绝，不泄漏对象内容。
- 报告 finding 包含 code、severity、path、message、observed 和 expected，并稳定排序；同租户同幂等键重放相同报告，参数不同返回 `IDEMPOTENCY_KEY_REUSED`，审计记录 actor、trace、输入/输出哈希。

补充场景：

- Given Variant 与 Canonical 相似度达到阈值且没有重复 Variant，When 检查，Then 相似度和重复度通过。
- Given Variant 与既有版本重复或相似度低于阈值，When 检查，Then 返回对应失败 finding 并包含冲突对象 ID。
- Given 标记为 AI 生成或广告内容但 disclosure 缺失/不匹配，When 检查，Then 返回 `AI_LABEL_MISSING` 或 `AD_DISCLOSURE_MISSING`/`AD_DISCLOSURE_MISMATCH`。
- Given 素材权利过期、撤回、地域/语言/用途不允许或跨租户，When 检查，Then 阻断并返回稳定权利 finding。
- Given 术语、相似度或权利 Port 临时失败，When 检查，Then 转为 `needs_review` warning，不伪造通过结论；确定性输入错误不重试。
