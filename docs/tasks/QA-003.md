## 实现规格

`SandboxRun` 字段：`id`、`org_id`、`input_hash`、`workspace_ref`、`image_digest`、`allowlisted_commands[]`、`network=none`、`secret_mounts=[]`、`cpu_ms`、`memory_mb`、`timeout_ms`、`status=queued|running|passed|failed|blocked|timed_out`、`stdout_ref`、`stderr_ref`、`created_at`。命令只允许任务级白名单（如 `pytest`、`ruff`、`mypy`），拒绝 shell 拼接、网络访问、生产路径和 secret/token 文件；超时或资源超限自动终止并保留证据哈希。

- `SandboxService.run` 接收结构化 argv 列表和临时工作区文件，不接受 shell 字符串；执行器使用 `shell=False`、隔离临时目录和剥离 secret/token 环境变量的最小环境。`network` 固定为 `none`，`secret_mounts` 固定为空，命令、参数和工作区路径均执行危险词与生产路径扫描。
- 默认允许 `pytest`、`ruff`、`mypy`、`python`；调用方可传入更窄的任务级白名单。每个命令必须以白名单可执行名开始，拒绝 shell 操作符、`curl`/`ssh`/`nc`/`Invoke-WebRequest`/`rm -rf` 等危险命令，阻断时不启动进程。
- 输入文件与依赖锁文件按排序后的路径和内容计算 `input_hash`；可选 `dependency_lock_hash` 必须与锁文件内容匹配。`cpu_ms`、`memory_mb`、`timeout_ms` 不得超过服务上限，超限标记 `blocked`。
- 运行结果符合 `sandbox-run.schema.json`，stdout/stderr 仅以 `private://` 引用暴露，原文不进入报告；内存证据索引记录输出哈希、退出码和状态。相同租户的 `input_hash + image_digest + command_set` 复用结果并标记 `reproducible=true`，同幂等键参数不一致返回 `IDEMPOTENCY_KEY_REUSED`。
