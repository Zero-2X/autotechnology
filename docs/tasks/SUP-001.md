## 实现规格

1. `SupportInboxService` 只接受 Fake/人工 comment 或 message，按 `external_message_id` 去重并保存消息哈希、意图、风险级别和线程版本。
2. 低风险 question/feedback/status 可生成脱敏草稿；草稿和线程均带 `send_blocked=true`，发送入口恒定返回 `SEND_DISABLED`。
3. 所有写入使用 TenantContext 与 Idempotency-Key，审计只保存哈希和分类元数据，不保存原始消息正文或 PII。

## 补充场景

- 重复外部消息不会增加线程 message_count；同幂等键 payload 改变返回 `IDEMPOTENCY_KEY_REUSED`。
- 未知来源、非法频道、空消息和草稿中的受限承诺确定性拒绝。
