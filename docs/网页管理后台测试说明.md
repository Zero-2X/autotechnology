# 网页管理后台测试说明

更新：2026-09-23。当前版本是本机可运行的管理后台：任务、账号、内容、客服草稿会同时保存到浏览器和本机 `.local/workflow-state.json`；小红书使用独立浏览器会话。文本模型已接入 `zpproxy` Responses，并已实测内容生成和低风险客服回复；Seedance 视频生成尚未接入。

## 打开网页

私有站点：https://ai-content-workflow-ops.irvahindsley62116.chatgpt.site

使用拥有该站点访问权的账号登录。未登录请求返回 401；这不代表业务 API 已接通。

本地启动（PowerShell）：

```powershell
cd D:\akagent
.\scripts\start-workflow.ps1
```

打开 http://127.0.0.1:8766/ 。该启动器同时启动网页和 API；看到页面顶部“API 已连接”后再操作。需要本机 Node.js、Python、Playwright 浏览器和 `requirements-browser.txt` 中的依赖。

如果页面显示“API 未连接”，请在项目根目录运行 `scripts\start-workflow.ps1`，等待终端同时显示 Web 和 API 地址，再重新打开 `http://127.0.0.1:8766/`。如果 API 已连接但小红书显示“需要重新登录”，请在账号的独立浏览器中重新扫码；首页可打开不代表消息区仍有有效会话。页面每 5 秒自动重试状态检查，不需要手动刷新。

账号卡片的“已连接”表示本机专用浏览器仍停留在创作者中心；客服页或发布编辑器仍可能单独失败。若失败时账号会话可用，页面会明确显示“账号已连接，但客服/发布操作失败”和具体原因；若本机 API 无法读取会话状态，才提示检查后台服务。客服扫描提示“未找到消息列表”表示需要在专用窗口手动进入消息/互动页，不是账号掉线。网页更新后若仍看到旧提示，按 `Ctrl+F5` 强制刷新。

有多个小红书账号时，在客服收件箱顶部先选择账号再打开客服或扫描当前页；点开某条已导入会话时，选择器会切换到这条消息绑定的账号。每个账号使用自己的本机浏览器会话。

首次使用可在 PowerShell 执行：

```powershell
cd D:\akagent
.\scripts\setup-browser-dependencies.ps1
```

现在也可以使用 `scripts\start-workflow.ps1` 同时启动 API 和网页；它默认使用 8766，打开 http://127.0.0.1:8766/。如果需要 8765，可显式传入 `-WebPort 8765`。

小红书账号登录准备：

```powershell
cd D:\akagent
.\scripts\start-xhs-login.ps1 -AccountKey xhs-9653254890
```

脚本会为该账号打开独立的创作者中心浏览器上下文。账号持有人自行完成扫码、验证码或登录；回到终端按 Enter 后保存会话目录。密码和验证码不进入网页、不写入聊天。当前脚本只准备登录会话，不点击发布。

登录完成后，API 会通过 `/internal/xhs/accounts/{account_key}/session` 回写脱敏状态，后台账号矩阵显示“登录会话已保存”。

生成并准备首篇草稿：

```powershell
python scripts\generate-demo-content.py
python scripts\prepare-xhs-draft.py --account-key xhs-9653254890
```

准备脚本只负责打开创作中心、尝试进入图文编辑器、填入本地生成的标题、正文和 PNG 封面，并在填充后暂停给运营人员检查。它不会点击最终发布按钮。若平台页面没有返回唯一的上传控件，脚本会停止并生成 `.tmp\xhs-editor-diagnostic.png`，需要先在浏览器中手动进入“图文”编辑器后再重试。

后台也提供 `POST /internal/content/drafts:generate`，输入 `{"topic":"你的选题","audience":"目标读者"}` 即可得到标题、正文、话题标签和 SVG 封面。模型配置可用时优先调用中转站，超时或模型拒绝时会退回本地模板。

客服草稿也有本地接口 `POST /internal/support/replies:generate`。低风险问题会生成可审核回复，高风险消息返回转人工标记，不会发送任何平台消息。

## 可以立即测试的内容

1. 任务管理：新增任务，填写负责人和截止时间，搜索、筛选、完成或删除任务；改动会同步到本机状态文件。
2. 账号矩阵：登记和编辑公开账号资料；平台字段可以填写小红书、抖音、TikTok、YouTube、Instagram 或其它平台。小红书账号可打开独立会话、进入客服窗口或跳到发布中心；没有已验证 API 或浏览器适配器的平台会在发布中心提供内容包导出。密码、验证码、Cookie 不进入后台数据。
3. 内容工作室：输入选题，生成本地标题、正文、话题和封面，审批后进入发布队列；内容可以再次编辑。
4. 发布中心：对小红书图文生成 PNG 封面并自动填入创作者中心；页面会报告启动、填稿或失败原因。默认不会点击最终发布按钮；发布中心另有“自动提交发布”入口，必须主动确认后才会尝试点击，点击后仍需检查平台回执，再登记平台对象 ID 或链接。
5. 客服收件箱：可把从小红书复制的评论或私信导入后台，按风险分类，生成和编辑回复草稿；绑定稳定消息标识的低风险会话可由操作者主动点击后交给小红书浏览器发送。无稳定标识、未知风险、中风险和高风险均不会由后台发送。发送动作只记录为“待平台核实”，须回到小红书确认后再标记完成。

账号矩阵中的“连接诊断”会逐项检查账号浏览器目录、会话记录和登录状态，并给出下一步提示；它不会显示 Cookie、验证码或其他凭据。

客服窗口现在会尝试进入创作者中心的消息/互动入口，并扫描页面上可识别的消息行。若平台在点击入口后才重定向到登录页，后台会记录 `login_required`，而不会误显示为普通失败；账号持有人扫码成功后，运行中的新版会话会自动更新连接状态。后台可将带有平台会话标识的回复交给浏览器适配器；只有找到唯一输入框和唯一“发送/回复”按钮时才会点击，否则返回人工处理。2026-09-23 的只读在线检查没有读取或发送任何消息，真实客服闭环仍未验收。

发布和客服中心的同账号窗口复用流程已修正：新版浏览器会接收排队任务；旧版运行器不会接收发稿或客服命令，避免新任务落入不支持的流程。若编辑器有未保存内容会停止，后台提示保存并关闭旧窗口，再重新打开账号。草稿填入成功后，后台会显示“草稿已准备好，请检查”，不会误把等待审核状态当成仍在处理中。这个流程需账号持有人重新登录并打开新版窗口后才能进行真实页面验收。

服务端使用 `MODEL_PROVIDER=zpproxy`、`MODEL_BASE_URL=https://webaiproxy.top/v1`、`MODEL_ID` 和 `OPENAI_API_KEY` 配置文本模型。当前默认模型为 `gpt-5.6-sol`；内容草稿与低风险客服回复会优先调用 Responses，中转站超时或拒绝时会自动回退本地模板。设置页“测试模型连接”会实际发起一条简短请求；它会显示连接耗时或安全的错误代码，不会显示密钥。当前 API 请求等待上限为 60 秒。
6. 连接与设置：首次打开自动检测 API；可以修改 API 地址、查看当前运行模式和开关。API 健康不代表平台发布权限，平台会话仍单独检查。
7. 数据备份：设置页可以导出任务、账号、内容和客服草稿，也可以导入此前导出的 JSON；导入后会重新检查账号会话，不会导入密码或验证码。

数据保存在当前浏览器 localStorage。刷新通常会保留记录；换浏览器、换域名或清理浏览器数据不会同步。请勿把它作为真实运营数据的唯一存储位置。预置的发稿数量、已发布内容、读者消息均为演示数据。

- 首个账号的公开主页链接，以及个人号、专业号或商家号类型。
- 是否有开发者应用、已获批的具体接口权限及其官方文档。
- 如果更换模型服务商或模型，提供其服务地址及准确模型 ID；密钥只在本机环境设置，避免粘贴到聊天或网页登记表。

账号登录或扫码授权由账号持有人在平台授权页完成。当前阶段提供密码或 Cookie 不会让未实现的适配器自动具备发布能力。
