# 网页管理后台测试说明

更新：2026-09-21。当前版本是浏览器本地存储的交互原型，尚未完成真实账号自动化业务闭环。

## 打开网页

私有站点：https://ai-content-workflow-ops.irvahindsley62116.chatgpt.site

使用拥有该站点访问权的账号登录。未登录请求返回 401；这不代表业务 API 已接通。

本地启动（PowerShell）：

```powershell
cd D:\akagent
.\scripts\start-web-console.ps1
```

打开 http://127.0.0.1:8765/ 。保留启动窗口；Ctrl+C 停止服务。需要本机 Node.js 和 Python，网页本身无第三方运行依赖。此启动器仅启动网页，不启动业务 API、模型或平台适配器。

现在也可以使用 `scripts\start-workflow.ps1` 同时启动 API 和网页；它默认使用 8766，打开 http://127.0.0.1:8766/。如果需要 8765，可显式传入 `-WebPort 8765`。

小红书账号登录准备：

```powershell
cd D:\akagent
.\scripts\start-xhs-login.ps1 -AccountKey xhs-9653254890
```

脚本会为该账号打开独立的创作者中心浏览器上下文。账号持有人自行完成扫码、验证码或登录；回到终端按 Enter 后保存会话目录。密码和验证码不进入网页、不写入聊天。当前脚本只准备登录会话，不点击发布。

登录完成后，API 会通过 `/internal/xhs/accounts/{account_key}/session` 回写脱敏状态，后台账号矩阵显示“登录会话已保存”。

生成并准备首篇草稿：

```powershell
python scripts\generate-demo-content.py
python scripts\prepare-xhs-draft.py --account-key xhs-9653254890
```

准备脚本只负责打开创作中心、尝试进入图文编辑器、填入本地生成的标题、正文和 PNG 封面，并在填充后暂停给运营人员检查。它不会点击最终发布按钮。若平台页面没有返回唯一的上传控件，脚本会停止并生成 `.tmp\xhs-editor-diagnostic.png`，需要先在浏览器中手动进入“图文”编辑器后再重试。

后台也提供 `POST /internal/content/drafts:generate`，输入 `{"topic":"你的选题","audience":"目标读者"}` 即可得到标题、正文、话题标签和 SVG 封面。它使用本地确定性模板，不依赖当前不可用的大模型，后续接入模型时可以保留同一个返回结构。

## 可以立即测试的内容

1. 任务管理：新增任务，填写负责人和截止时间，搜索、筛选、完成或删除任务。
2. 账号矩阵：登记平台、名称、公开标识、负责人和内容栏目。登记不等于授权，编辑按钮目前只是占位提示。
3. 内容工作室：输入选题，创建演示草稿记录，批准后进入发布队列。当前生成的是固定占位文本，没有调用 AI；内容详情按钮也尚未接通编辑器。
4. 发布中心：查看待审核及已批准记录。人工导出按钮目前只显示提示，没有生成下载文件，更没有向小红书发稿。
5. 客服收件箱：查看演示会话，保存回复草稿；高风险演示会话禁用草拟按钮。没有获取真实评论或私信，也没有发送回复。
6. 连接与设置：保存页面设置及检测 API 健康地址。健康检查成功不代表管理数据已对接 API，开关不会改变后台策略。

数据保存在当前浏览器 localStorage。刷新通常会保留记录；换浏览器、换域名或清理浏览器数据不会同步。请勿把它作为真实运营数据的唯一存储位置。预置的发稿数量、已发布内容、读者消息均为演示数据。

## 尚需实现与验证

- 管理页面接入后端持久化存储、身份认证、权限和审计；打通账号、任务、正文编辑、素材上传、版本及发布回执。
- 配置真实模型供应商，在服务器保存密钥，验证内容生成、错误处理和用量记录。
- 根据测试账号实际获批的能力实现小红书适配器。账号登录授权不等于拥有笔记发布、评论或私信权限；不能假设获得 OAuth 后所有功能都可用。
- 分别验证内容发布与回查、消息获取、回复发送；建立幂等、失败处理、频率控制和停止开关。
- 通过真实单账号端到端测试后，再启用定时运行和多账号矩阵。

## 用户需提供的起始信息

- 首个账号的公开主页链接，以及个人号、专业号或商家号类型。
- 是否有开发者应用、已获批的具体接口权限及其官方文档。
- 准备使用的模型服务商和模型；密钥后续通过服务器本地配置输入，不发送到聊天或网页登记表。
- 首篇内容主题、目标受众、自有素材，以及客服 FAQ 和需要转人工的问题范围。

账号登录或扫码授权由账号持有人在平台授权页完成。当前阶段提供密码或 Cookie 不会让未实现的适配器自动具备发布能力。
