# 网页管理后台测试说明

更新：2026-09-22。当前版本是本机可运行的管理后台：任务、账号、内容、客服草稿会同时保存到浏览器和本机 `.local/workflow-state.json`；小红书使用独立浏览器会话。大模型接入仍按要求暂缓。

## 打开网页

私有站点：https://ai-content-workflow-ops.irvahindsley62116.chatgpt.site

使用拥有该站点访问权的账号登录。未登录请求返回 401；这不代表业务 API 已接通。

本地启动（PowerShell）：

```powershell
cd D:\akagent
.\scripts\start-workflow.ps1
```

打开 http://127.0.0.1:8766/ 。该启动器同时启动网页和 API；看到页面顶部“API 已连接”后再操作。需要本机 Node.js、Python、Playwright 浏览器和 `requirements-browser.txt` 中的依赖。

如果页面显示“API 未连接”或“小红书未连接”，通常是直接打开了旧页面、只启动了网页而没有启动 API，或本机服务刚刚启动还没有完成。请关闭旧页面，在项目根目录运行 `scripts\start-workflow.ps1`，等待终端同时显示 Web 和 API 地址，再重新打开 `http://127.0.0.1:8766/`。页面现在会每 5 秒自动重试连接，不需要手动刷新；如果账号窗口被关闭，账号卡片会明确显示“后台接口未响应”或“需要重新登录”。

首次使用可在 PowerShell 执行：

```powershell
cd D:\akagent
.\scripts\setup-browser-dependencies.ps1
```

现在也可以使用 `scripts\start-workflow.ps1` 同时启动 API 和网页；它默认使用 8766，打开 http://127.0.0.1:8766/。如果需要 8765，可显式传入 `-WebPort 8765`。

小红书账号登录准备：

```powershell
cd D:\akagent
.\scripts\start-xhs-login.ps1 -AccountKey xhs-9653254890
```

脚本会为该账号打开独立的创作者中心浏览器上下文。账号持有人自行完成扫码、验证码或登录；回到终端按 Enter 后保存会话目录。密码和验证码不进入网页、不写入聊天。当前脚本只准备登录会话，不点击发布。

登录完成后，API 会通过 `/internal/xhs/accounts/{account_key}/session` 回写脱敏状态，后台账号矩阵显示“登录会话已保存”。

生成并准备首篇草稿：

```powershell
python scripts\generate-demo-content.py
python scripts\prepare-xhs-draft.py --account-key xhs-9653254890
```

准备脚本只负责打开创作中心、尝试进入图文编辑器、填入本地生成的标题、正文和 PNG 封面，并在填充后暂停给运营人员检查。它不会点击最终发布按钮。若平台页面没有返回唯一的上传控件，脚本会停止并生成 `.tmp\xhs-editor-diagnostic.png`，需要先在浏览器中手动进入“图文”编辑器后再重试。

后台也提供 `POST /internal/content/drafts:generate`，输入 `{"topic":"你的选题","audience":"目标读者"}` 即可得到标题、正文、话题标签和 SVG 封面。它使用本地确定性模板，不依赖当前不可用的大模型，后续接入模型时可以保留同一个返回结构。

客服草稿也有本地接口 `POST /internal/support/replies:generate`。低风险问题会生成可审核回复，高风险消息返回转人工标记，不会发送任何平台消息。

## 可以立即测试的内容

1. 任务管理：新增任务，填写负责人和截止时间，搜索、筛选、完成或删除任务；改动会同步到本机状态文件。
2. 账号矩阵：登记和编辑公开账号资料；小红书账号可打开独立会话、进入客服窗口或跳到发布中心。密码、验证码、Cookie 不进入后台数据。
3. 内容工作室：输入选题，生成本地标题、正文、话题和封面，审批后进入发布队列；内容可以再次编辑。
4. 发布中心：对小红书图文生成 PNG 封面并自动填入创作者中心；页面会报告启动、填稿或失败原因。默认不会点击最终发布按钮；发布中心另有“自动提交发布”入口，必须主动确认后才会尝试点击，点击后仍需检查平台回执，再登记平台对象 ID 或链接。
5. 客服收件箱：可把从小红书复制的评论或私信导入后台，按风险分类，生成和编辑回复草稿，复制到小红书窗口；发送完成后可标记“已发送”。高风险问题自动转人工。

账号矩阵中的“连接诊断”会逐项检查账号浏览器目录、会话记录和登录状态，并给出下一步提示；它不会显示 Cookie、验证码或其他凭据。

如果服务端环境中设置了 `MODEL_PROVIDER=zpproxy` 和 `OPENAI_API_KEY`，内容草稿与低风险客服回复会优先调用中转站模型；模型超时、拒绝或暂时不可用时，会自动回退到本地模板，并在结果中保留回退原因。设置页只显示“已配置”和模型名称，不显示密钥。
6. 连接与设置：首次打开自动检测 API；可以修改 API 地址、查看当前运行模式和开关。API 健康不代表平台发布权限，平台会话仍单独检查。
7. 数据备份：设置页可以导出任务、账号、内容和客服草稿，也可以导入此前导出的 JSON；导入后会重新检查账号会话，不会导入密码或验证码。

数据保存在当前浏览器 localStorage。刷新通常会保留记录；换浏览器、换域名或清理浏览器数据不会同步。请勿把它作为真实运营数据的唯一存储位置。预置的发稿数量、已发布内容、读者消息均为演示数据。

## 尚需实现与验证

- 管理页面的本机持久化已完成；服务器身份认证、多人权限、正式审计数据库和跨机器部署仍需建设。
- 配置真实模型供应商，在服务器保存密钥，验证内容生成、错误处理和用量记录。
- 根据测试账号实际获批的能力实现小红书适配器。账号登录授权不等于拥有笔记发布、评论或私信权限；不能假设获得 OAuth 后所有功能都可用。
- 评论/私信自动抓取和自动发送没有稳定的公开权限证据，当前使用人工复制、草拟、人工发送、后台登记的闭环；若以后取得官方权限，再单独增加回执、幂等、频率控制和停止开关。
- 通过真实单账号端到端测试后，再启用定时运行和多账号矩阵。

## 用户需提供的起始信息

- 首个账号的公开主页链接，以及个人号、专业号或商家号类型。
- 是否有开发者应用、已获批的具体接口权限及其官方文档。
- 准备使用的模型服务商和模型；密钥后续通过服务器本地配置输入，不发送到聊天或网页登记表。
- 首篇内容主题、目标受众、自有素材，以及客服 FAQ 和需要转人工的问题范围。

账号登录或扫码授权由账号持有人在平台授权页完成。当前阶段提供密码或 Cookie 不会让未实现的适配器自动具备发布能力。
